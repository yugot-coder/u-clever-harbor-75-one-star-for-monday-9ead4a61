A one-star review of Monday, written as though Monday were a restaurant — one line, 23 words, short enough to screenshot into the group chat:

> Booked a table for a quiet morning. Monday sat me next to my alarm, served cold coffee, and billed me for the weekend.

## Run it

```sh
python3 main.py
```

It writes the review to `entry.txt` in the output directory (`/output/entry.txt` when that directory exists, otherwise next to `main.py`). Standard library only, fully deterministic — running it twice produces byte-identical output.

## How it is built

- `main.py` — the make.fun hand-in program: writes the chosen review to `entry.txt`.
- `CANDIDATES.md` — the 10 candidates considered, with word/character counts and the reason the chosen line won.
